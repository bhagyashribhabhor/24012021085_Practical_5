# Practical 5: Login and Registration Using Jetpack Compose

## 🎯 Aim
To create an Android application that includes Login and Registration screens using Jetpack Compose.

## 📖 Study
- Jetpack Compose
- Composable Functions
- Text Fields
- Buttons
- UI Layouts
- State Management
- Android UI Development

## 📝 Project Description
This Android application demonstrates how to create Login and Registration screens using Jetpack Compose and Kotlin. It provides a user interface for entering login credentials and registration details using Compose UI components.

## ✨ Features
- Login screen UI
- Registration screen UI
- Input fields for user details
- Buttons for login and registration actions
- Modern Android UI built using Jetpack Compose
- Reusable composable functions

## 🛠️ Technologies Used
- **Language:** Kotlin
- **IDE:** Android Studio
- **UI Toolkit:** Jetpack Compose
- **Platform:** Android

## ⚙️ Concepts Used

### 1. Jetpack Compose
A modern Android UI toolkit used to build native user interfaces with Kotlin.

### 2. Composable Functions
Functions annotated with `@Composable` that define and display UI elements.

### 3. Text Fields
Used to accept user input, such as email, username, and password.

### 4. Buttons
Used to perform actions when the user interacts with the application.

### 5. State Management
Used to manage and update UI values when the user enters information or interacts with the screen.

## ▶️ How to Run
1. Clone or download this repository.
2. Open the project in Android Studio.
3. Wait for Gradle synchronization to finish.
4. Run the application on an Android emulator or physical device.
5. Explore the Login and Registration screens.

## 📚 Learning Outcomes
- Understand the basics of Jetpack Compose.
- Learn to create Android user interfaces using Kotlin.
- Understand composable functions and UI components.
- Learn to accept user input using text fields.
- Understand the basic design of Login and Registration screens.
